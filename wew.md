### Orchestrator Groups Translation Unit Roles (`UnitRole`)

Gorups of Unit Roles Translations in Right Panel Translation Review:

| Unit Role | Code Identifier | Description / Source |
| :--- | :--- | :--- |
| **Group: Title Pages** |  |  |
| **Cover Titles** | `cover_title` | Primary publication title and subtitle (`title2`) |
| **Table Titles** | `table_title` | Titles and sub-captions of statistical tables |
| **Chart Titles** | `chart_title` | Main titles of chart cards |
| **Map Titles** | `map_title` | Titles and layer headers of thematic map cards |
| **Image Captions** | `image_caption` | Figure, diagram, and image captions |
| **Card Titles** | `card_title` | Generic card-level titles |
| **Group: Narrative Pages** |  |  |
| **Narrative Titles** | `narrative_title` | Chapter and section headings on narrative/analysis cards |
| **Narrative Bodies** | `narrative_body` | Individual paragraphs within narrative text cards |
| **Group: Table Pages** |  |  |
| **Table Headers** | `table_header` | Column and stacked multi-level headers (split by `--`) |
| **Table Row Labels** | `table_row_label` | First column stub labels / category rows in tables |
| **Table Notes** | `table_note` | Footnotes, source lines (`Sumber: ...`), and notes (`Catatan: ...`) |
| **Group: Other Pages** |  |  |
| **Chart Series** | `chart_series` | Legend and data series labels (`series_*_label`) |
| **Table of Contents** | `toc_title` | Table of Contents section labels and headings |
| **Divider Titles** | `divider_title` | Chapter break and divider page titles |
| **Headers & Footers** | `header_footer` | Running header and running footer templates |
